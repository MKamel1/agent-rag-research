## 4. State of the system (for the operator)

**Solid.** Grounding (raw blocks never rewritten; every result resolves; `get_span` round-trips), single-sourced fusion, correct reranker batching, and an eval harness that keeps answerable and absent separate. Five corpora are consistent in SQLite, and sparse IDF is applied on all of them. The topic labels pass their audit, and the new GT sets were authored blind and verified verbatim. Merged CQ-1 is safe: it changes none of 1,217 recorded queries and improves `scan_corpus`.

**Unknown.** Every quality question that matters is unmeasured on the new sets: passage-level recall, whether stubs or ligatures cost results, whether off-topic papers enter answers, and whether per-corpus depth and weight settings help. Whether the cross-encoder score can tell "answerable" from "absent" was never tested; the earlier "no floor" verdict tested rank arithmetic only. Whether filtered searches (summaries, books, org) lose results without payload indexes is also unknown. Two of these are CPU-only measurements once Qdrant is up. The rest need one GPU session, and that session is blocked by a foreign Ollama process, not by this system.

**At risk.** (1) Data: the main corpus has no backup newer than July 30, nothing is off this disk, and the disk is 98% full. This is the only finding whose downside is unrecoverable. (2) Measurement integrity: as written, the first GPU run would rewrite its own fixture, measure a different checkout, record no hash, and score correct alternative passages as misses. Fix that before the run, or the baseline is not a baseline. (3) Silent wrong answers: an unknown `paper_id` returns an empty result instead of an error, a mispointed eval or server produces a confident wrong number, and a held GPU lock looks like "service down". (4) Structure: standards and the 15 books have broken section paths (running headers, stale clause numbers, no chapters). The cause is known and fixable on CPU, but the fix needs a re-embed, so it should wait for a baseline that shows it costs answers.
