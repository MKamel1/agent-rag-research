# Waymo AV-Safety Corpus Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (Per this
> user's standing preference, always subagent-driven for this project — don't re-ask.)

**Goal:** Harvest, score, and ingest the arXiv-side Waymo AV-safety corpus described in
`docs/ONBOARDING_AND_ARXIV_KEYWORDS.md`, into a corpus **isolated** from the existing
causal-inference/causal-ML corpus this repo already serves — same repo, same shared services
(Qdrant/TEI/GROBID/Ollama), different data dir + Qdrant collection + dashboard port.

**Architecture:** Two-phase, not one. Phase A is a standalone scouting script that queries arXiv's
public API directly with the onboarding doc's real boolean/author queries (outside this repo's
`ArxivSource`, which only supports flat `all:"term"` keywords by design — see "Why not
`focus_area_queries`" below) and writes a scored, deduplicated, already-captured-excluded
candidate list to disk. A human checkpoint reviews that list. Phase C feeds the approved ID list
into this repo's existing `app.ingest --paper-ids-file` fixed-corpus path (already used for eval
corpora) to run the real harvest→parse→chunk→summarize→embed→store pipeline — no core-pipeline
code changes.

**Tech Stack:** Python 3 stdlib (`xml.etree.ElementTree`, `httpx` via the repo's existing
`rag.harvester.arxiv_http_client`), this repo's existing `app.init_config` / `app.doctor` /
`app.ingest` / `scripts/dashboard.sh` tooling. No new dependencies.

## Global Constraints

- Never touch `rag/harvester.py`'s `ArxivSource._build_query` — its quote/backslash rejection is a
  deliberate injection-safety fix (OG-49#6/M7) for dashboard-editable input; this project's queries
  are operator-fixed literals evaluated in a standalone script instead, not routed through that
  method.
- Never mix Waymo AV-safety content into the `papers` Qdrant collection or
  `research-system-rag-data/` — confirmed with the user: fully isolated, and everything lives
  under this repo's own working directory (`waymo/` here), not an external folder.
- Respect arXiv's rate-limit ask: no more than 1 request / 3 seconds (`rag.harvester._RATE_LIMIT_SECONDS`),
  and always send the repo's existing descriptive `User-Agent` (`rag.harvester.arxiv_http_client`).
- GPU-heavy work (parse/embed) for this corpus must never run concurrently with the main corpus's
  GPU-heavy work — this machine has prior OOM history (`docs/RUNBOOK.md`). Both configs share one
  physical `gpu_lock_path`.

## Why not `focus_area_queries`? (context every task assumes)

`rag/harvester.py::ArxivSource._build_query` wraps every focus-area term as `all:"<term>"` and
**rejects** any `"` or `\` in it (injection-safety fix, `_UNSAFE_QUERY_CHARS_RE`). The onboarding
doc's query set is rich Lucene syntax — quoted phrases, `AND`/`OR`, field-scoped `au:Kusano_K AND
(...)` author search — none of which that method can express. There is no `au:` support anywhere
in this repo's harvest path at all.

Decomposing the doc's queries into ~25 flat keywords and running them through
`focus_area_queries` would lose precision (a paper only needs to contain one bare phrase anywhere,
not the doc's actual AND-combined conditions) and drop author search entirely — the doc's own
priority #1.

Instead: Phase A talks to `https://export.arxiv.org/api/query` directly with the doc's real query
strings (this is safe here because the strings are fixed literals an operator wrote and reviewed,
not runtime-editable dashboard input — the exact threat `_build_query`'s rejection defends
against). Phase C then hands the resulting **fixed arXiv-ID list** to
`app.ingest --paper-ids-file`, which already exists for exactly this shape of problem (T-EVAL,
OG-40 — guaranteeing a known, fixed paper set ends up in a corpus, same mechanism this repo's own
eval fixtures use) and requires zero code changes.

def _base_id(raw_id_url: str) -> str:
    """'http://arxiv.org/abs/2401.99999v2' -> '2401.99999' (strip URL prefix + version suffix)."""
    tail = raw_id_url.rsplit("/", 1)[-1]
    return re.sub(r"v\d+$", "", tail)


def parse_atom_entries(feed_xml: str) -> list[dict]:
    root = ET.fromstring(feed_xml)
    entries = []
    for entry in root.findall(f"{_ATOM_NS}entry"):
        entries.append({
            "id": _base_id(entry.findtext(f"{_ATOM_NS}id", "")),
            "title": " ".join(entry.findtext(f"{_ATOM_NS}title", "").split()),
            "summary": " ".join(entry.findtext(f"{_ATOM_NS}summary", "").split()),
            "authors": [
                a.findtext(f"{_ATOM_NS}name", "") for a in entry.findall(f"{_ATOM_NS}author")
            ],
            "categories": [
                c.get("term", "") for c in entry.findall(f"{_ATOM_NS}category")
            ],
            "published": entry.findtext(f"{_ATOM_NS}published", ""),
        })
    return entries


def score_text(text: str) -> int:
    text = text.lower()
    return sum(weight for kw, weight in _KEYWORD_WEIGHTS.items() if kw in text)


def dedup_by_id(entries: list[dict]) -> list[dict]:
    seen: dict[str, dict] = {}
    for e in entries:
        seen.setdefault(e["id"], e)
    return list(seen.values())


def _run_query(client, query: str, sleep) -> list[dict]:
    entries: list[dict] = []
    start = 0
    while start < _MAX_RESULTS_PER_QUERY:
        resp = client.get(_API_URL, params={
            "search_query": query, "start": start, "max_results": _PAGE_SIZE,
            "sortBy": "relevance", "sortOrder": "descending",
        })
        resp.raise_for_status()
        page = parse_atom_entries(resp.text)
        if not page:
            break
        entries.extend(page)
        start += _PAGE_SIZE
        sleep(_RATE_LIMIT_SECONDS)
    return entries


def scout(sleep=time.sleep) -> list[dict]:
    client = arxiv_http_client(30.0)
    raw: list[dict] = []
    for query in _TOPIC_QUERIES:
        raw.extend(_run_query(client, f"{query} AND {_CATEGORY_FILTER}", sleep))
    for query in _AUTHOR_QUERIES:
        raw.extend(_run_query(client, query, sleep))

    deduped = dedup_by_id(raw)
    kept = [
        {**e, "score": score_text(e["title"] + " " + e["summary"])}
        for e in deduped
        if e["id"] not in ALREADY_CAPTURED_IDS
    ]
    scored = [e for e in kept if e["score"] > 0]
    scored.sort(key=lambda e: e["score"], reverse=True)
    print(
        f"waymo_arxiv_scout: {len(raw)} raw hits -> {len(deduped)} unique -> "
        f"{len(kept)} after excluding {len(deduped) - len(kept)} already-captured -> "
        f"{len(scored)} after dropping score-0",
        file=sys.stderr,
    )
    print("Top 20 by relevance score:", file=sys.stderr)
    for e in scored[:20]:
        print(f"  [{e['score']:>2}] {e['id']}  {e['title'][:90]}", file=sys.stderr)
    return scored


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--out", required=True, help="path to write candidates.json")
    args = parser.parse_args()
    candidates = scout()
    Path(args.out).write_text(json.dumps(candidates, indent=2))
    print(f"waymo_arxiv_scout: wrote {len(candidates)} candidates to {args.out}", file=sys.stderr)


if __name__ == "__main__":
    main()
